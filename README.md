📌 IMDB Movie Analysis — Data Analytics Project
🎯 Objective

As a data analyst intern at IMDB, your task is to explore and analyze the IMDB Movies dataset.
The goal is to:

Answer key business questions

Identify movie trends

Understand genre popularity

Analyze rating patterns

Study factors influencing movie success

Provide actionable insights

Using Python and libraries such as Pandas, NumPy, Seaborn, and Matplotlib, this project performs a complete exploratory data analysis (EDA) to help IMDB make data-driven decisions.

🧭 Project Workflow

This project follows a structured analytical workflow with 9 tasks, each designed to answer specific business questions.

1️⃣ Project Setup and Data Loading

Task: Load the dataset and perform initial setup.

✔ Questions:

What libraries are required for this project, and why?

What is the shape of the dataset?
What does each row and column represent?

2️⃣ Data Overview & Basic Exploration

Task: Explore the structure and composition of the dataset.

✔ Questions:

Use .info() to identify data types & missing values.

Use .describe() to analyze dataset distribution.

3️⃣ Data Cleaning

Task: Address missing values, incorrect data types & outliers.

✔ Questions:

Which columns contain missing values?

Are any columns stored in the wrong data type (e.g., dates, ratings)?

4️⃣ Univariate Analysis

Task: Explore each column individually.

✔ Questions:

What is the distribution of movie runtimes?

What are the most common genres?

5️⃣ Bivariate Analysis

Task: Analyze relationships between two variables.

✔ Questions:

Does runtime affect rating?

How do ratings vary by genre?

Is there a correlation between budget, votes, and revenue?

6️⃣ Genre-Specific Analysis

Task: Deep dive into performance of movie genres.

✔ Questions:

Which genre has the highest average rating?

How does genre popularity change over time?

7️⃣ Year & Trend Analysis

Task: Analyze long-term patterns.

✔ Questions:

How have movie ratings changed over the years?

Which years had the highest and lowest number of releases?

8️⃣ Multivariate Analysis

Task: Explore complex relationships using multiple variables.

✔ Questions:

Most popular genres by decade

Correlation heatmap & pairplot

High-rated genres or years

9️⃣ Insights & Summary

Task: Summarize key findings.

✔ Questions:

Three major insights from the entire analysis

Additional questions or datasets that could deepen the analysis

📝 Key Insights (Sample Summary)

Drama, Fantasy, Crime, and Animation are consistently high-performing genres.

Budget and revenue show a strong positive correlation—big budgets usually mean big returns.

Ratings remained stable from 1980–2020 but declined after 2020.

The 2010s saw the highest number of movie releases.

Genre popularity and rating trends vary significantly across countries.
